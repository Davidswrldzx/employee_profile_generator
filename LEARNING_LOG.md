## What I will remember

Spaces count as characters. When joining strings, I need to add spaces where I want them to appear.

Numbers need to be converted to strings before joining them to text with `+`.

A slice includes the start index and stops before the end index. Negative indexes count from the end of the string, starting with `-1`.
